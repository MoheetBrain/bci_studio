## 3 · What the studio's statements rest on

- **Chip statements** (names, lines, ports, what is and is not implemented, which suites cover what): extracted
  mechanically from the snapshot, or quoted verbatim from a project document; tests fail if either stops being true.
- **Atlas statements** (names, ids, positions, extents): computed from the atlas files.
- **Neuroscience statements attributed to an article whose abstract was read**: worded to stay within the abstract.
- **Neuroscience statements attributed to an article with no abstract available** (the seven listed above) or to the
  textbook: written from the engineering agent's prior knowledge of well-known literature. They have **not** been
  checked against the text in this build. The app shows this reading level next to each source. They need expert
  review before being relied on.
- **No page number, chapter number or figure number appears anywhere**, because no full text was retrieved.
- **Lesson numbers** (signal amplitudes, noise, codes): outputs of a stated model with a seed. Synthetic, not data.

## 5 · Retrieval

- **Method:** SQLite FTS5 with porter stemming and BM25 (heading weighted ×3), a short table of domain synonyms
  (MUX ↔ multiplexer, AFE, ADC, M1 …), and per-side retrieval for "A versus B" questions. Served by the dev/preview
  server on 127.0.0.1 only, read-only.
- **This is keyword retrieval, not an answer system.** No language model is configured, no embedding index exists,
  and nothing is generated. A query the corpus cannot support is reported as unsupported.
- **Evaluation** (`docs/evidence/retrieval-eval.txt`):
  - Development set (visible while the rules were written): 20/20 answerable in the top 3; 5/5 unanswerable refused.
  - **Held-out set** (written after the rules were frozen, not used for tuning): **14/15** answerable in the top 3
    (13/15 at rank 1); **5/5** unanswerable refused. The miss: "RAW versus FEATURE records" returned three other
    project documents that discuss both before the expected ones (rank 4).
  - Both sets are small (25 and 20 questions) and were written by the same agent that built the index; treat the
    numbers as a sanity check, not a benchmark.
- **Semantic retrieval was not added**: nothing measured here shows it would improve on the baseline.

## 6 · Privacy

Abstracts and anything in `corpus/private/` stay on this machine: git-ignored, absent from the build output, never
sent anywhere. The only network calls made while building were to GitHub (cloning references), Crossref (verifying
DOIs) and NCBI E-utilities (fetching abstracts by DOI); none carried project or personal data. The app itself makes
no external requests and records no analytics.
